## 🛠️ Installation

1. Download the latest template XML file.
2. Open your **Blogger Dashboard**.
3. Go to **Theme**.
4. Select **Backup** and save your current theme.
5. Choose **Edit HTML** or upload the XML theme where supported.
6. Paste/upload the new template.
7. Save the theme.
8. Visit your blog and customize the available widgets and settings.

> ⚠️ Always create a backup of your existing Blogger theme before installing a new template.
